# List

> Ordered or unordered list with ghost loading and per-item icons. Accepts content as a `ReactNode[]` array or as `children` with `Li` sub-components. Use for feature lists, steps, terms, or any repeated content that needs a loading skeleton.

<br/>

## Features

- Ordered or unordered list type
- Configurable list style type
- Per-item icon slot
- Ghost loading with `expectedLines`
- Dual rendering — `content` array and `children` compose together

<br/>

## Component Definition

### Semantics & HTML
- Native `<ol>` element by default — `type="ul"` switches to `<ul>`. Both carry implicit `role="list"`

### Li sub-component
- Native `<li>` element with color, size, and optional icon support
- Icons absolutely positioned left within the item — size scales with the `size` prop
- `isLoading` replaces children with a Ghost skeleton
- No `forwardRef` — Li is a presentational sub-component

### Accessibility (WAI-ARIA)
- `<ol>`/`<ul>` carries implicit `role="list"` — screen readers announce list semantics and item count
- Ghost loading: each Li renders a Ghost with `role="status"` — screen readers announce loading state per item

### Responsive & Layout
- Left-padded block element — indent accommodates list markers or icons
- Icons absolutely positioned within Li, aligned to the padding area
- Ghost skeletons render at partial width — mimics natural text length variation

<br/>

## Architecture Decisions
- **Dual content API**: `content` array for simple cases, `children` for full control with custom `Li` instances. Both can be used simultaneously (`content` renders first, `children` append after)
- **Li icon via descendant selector**: Targets direct SVG children — works with any icon library, no wrapper element needed

# P

> Basic paragraph component with ghost loading placeholders. Wraps native `<p>` with color theming, size tokens, text alignment, and a skeleton loading state that renders deterministic-width Ghost lines. Use for body text, descriptions, and any multi-line content that needs a loading skeleton.

<br/>

## Features

- Ghost loading with `expectedLines`
- Text and ghost alignment — left, center, right

<br/>

## Component Definition

### Semantics & HTML
- Native `<p>` element — implicit paragraph semantics, no ARIA role override needed
- `whitespace-pre-wrap` base class — preserves whitespace and line breaks in text content

### Accessibility (WAI-ARIA)
- Native `<p>` element has no required ARIA roles or attributes
- Text content replaced entirely during loading — no stale text in the accessibility tree

### Responsive & Layout
- Block element, inherits parent width
- Loading state switches to vertical flex layout — ghost alignment follows the `align` prop
- Ghost skeletons render with varied but consistent widths across lines — natural-looking without layout shift between renders

<br/>

## Architecture Decisions
- **Deterministic ghost widths**: Ghost lines use a deterministic formula per index instead of random widths — avoids layout shift between renders and SSR hydration mismatches while producing natural-looking variation
- **Silent ghosts**: No `role="status"` on ghost lines — a page with multiple loading P's would flood screen readers with duplicate announcements. If a specific section needs a loading announcement, add `role="status"` to the `<p>` via native props

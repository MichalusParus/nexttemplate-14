# NextTemplate

Next.js environment for [ParusUI](src/components/_docs/docs.mdx) — a custom component library.

## Quick Start

```bash
pnpm install
pnpm storybook
```

Run Storybook for full ParusUI documentation — component stories, definitions, and reference pages.
